# Directness conventions in force (organizers' definitions, as applied on 11-19 and 11-20)

- Class is the FORM of the experiment for THIS hypothesis's A and B. Varying APOE genotype/isoform (incl. carriers vs non-carriers) is A itself; the model system never lowers the class.
- B is taken exactly as the hypothesis defines it, including location (e.g. "in the endo-lysosome"); a readout that matches B except for that context is a surrogate B' (class 3).
- Class 1 takes strength 1 (the organizers' table: strength 2 means a surrogate). A tight surrogate with no plausible other route is class 3, strength 2.
- Class 2 needs a surrogate A' assumed to change A. A manipulation that does not act on APOE (a drug, a knockdown, a lipid or cargo manipulation) within one genotype is class 5, and its reason goes into the Finding description ("Class 5 (other): ...").
- Class 4 strength is not below 3.
- Same readout measured the same way => same class and strength as the reference rows of that hypothesis (listed below the rows).
- H5 conventions: lysosomal degradation assays (DQ-BSA, cargo turnover sensitive to lysosomal inhibitors), cathepsin activity, lysosomal/late-endosomal pH, autophagic flux (LC3-II turnover with bafilomycin/chloroquine, tandem LC3 reporter) = 1/1. Lysosomal membrane damage/leakage = 3/2. Lysosomal cholesterol/lipid accumulation = 3/3. Lipofuscin = 3/4. Cargo/receptor/apoE colocalization with LE/lysosome markers, LysoIP cargo, accumulated pHrodo cargo = 3/4. Static LC3/p62 without flux = 3/3; upstream machinery (Beclin1/ATG7) = 3/4. LAMP1/LAMP2/CD63/CD68/RAB7/cathepsin D markers, LysoTracker, lysosomal proteomics = 3/3. Class 5: strength 4 when the readout is B or a tight surrogate, 5 when a looser surrogate.
- H3: aggregation of purified protein in a tube (no endo-lysosome) is a surrogate: class 3.
